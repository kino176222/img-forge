# img-forge — Macの中に置く、画像の鍛冶場

Apple Silicon（M1以降）のMacで、Stable Diffusion系の画像生成を**自分のパソコンの中だけ**で動かすWebアプリです。
ブラウザからプロンプトを入れて焼く、寝ている間に100枚バッチで焼く、焼けた絵を高速で仕分ける——このあたりを一式でまかないます。

**何枚焼いても料金はかかりません。**かかるのは電気代だけです。

> 作者（Kino）が自分用に作って、自分で毎日使っている道具です。完璧な製品ではなく、**改造してもらう前提の叩き台**として配っています。

---

## 動く環境（ここは正直に）

| 項目 | 条件 |
|---|---|
| マシン | **Apple Silicon Mac**（M1以降。作者はM4で開発・確認） |
| メモリ | 16GB以上を推奨（8GBは厳しい） |
| ディスク | モデル1本あたり6〜7GB。最低でも30GBは空けておく |
| Python | 3.10以上（作者は3.12） |

**Intel Macでは動きません。Windows / Linuxも対象外です**（GPUの呼び出し方がApple製チップ専用のため）。

生成速度の目安は、1024px級で**1枚あたり2分前後**。速さで殴るタイプではないので、「寝る前に仕込んで朝見る」使い方が向いています。

---

## できること

- **単発生成** — プロンプトを入れて、モデルを選んで、枚数を決めて焼く
- **夜間バッチ** — プロンプトを並べたテキストファイルを渡すと、順番に全部焼く
- **レビュー** — 焼けた画像を一覧して、キーボードで採用／ボツを高速に仕分ける
- **スタイル（当たり設定の保存）** — モデル・絵柄タグ・ネガティブをまとめて名前で保存。絵柄だけ固定して、中身は毎回自由に
- **XYZスイープ** — 設定を総当たりで焼いて比較表にする。新しいモデルの「当たり値探し」用
- **兄弟を8枚焼く** — 惜しい絵を出発点に、構図と色を保ったまま細部違いを量産
- **自動採点** — 8枚以上焼くとアニメ美的スコアを付けて、点数順に並べられる
- **モデル管理** — Civitaiのカタログを検索して、その場でダウンロード・登録

### いちばんおすすめの使い方

このアプリは**コマンドラインからも全部叩けます**。なので、Claude CodeのようなターミナルのAIエージェントに、

> 「こういうイメージで100枚焼いといて」

と日本語で頼むと、プロンプトを100本考えるところからバッチ投入まで全部やってくれます。
**焼くのが無料だから、数打てば当たるを正面からやれる**——これがこの道具の一番おいしいところです。

## セットアップ（約15分＋モデルのダウンロード時間）

### 1. フォルダを置く

zipを展開して、好きな場所に置いてください。パスの決め打ちはしていないので、どこでも動きます。

```
img-forge/
├── generate.py       … 生成本体（コマンドライン）
├── dashboard.py      … Webダッシュボード
├── fetch_model.py    … モデル追加ツール
├── models.json       … モデル台帳（当たり設定はここに入っています）
├── styles.json       … スタイル（絵柄プリセット）
└── requirements.txt  … 依存パッケージ
```

### 2. Pythonの環境を作る

ターミナルで `img-forge` フォルダに移動して、以下を順に実行します。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
```

PyTorchなど大きいものが入るので、回線によっては10分ほどかかります。

> **ここが最短ルート**: このフォルダごとClaude CodeなどのAIエージェントに読ませて「READMEの通りにセットアップして」と頼むと、たいてい全部やってくれます。

### 3. モデルを1本ダウンロードする

**モデル本体は配布物に含まれていません**（サイズと権利の都合です）。各自でダウンロードしてください。

```bash
# 台帳に登録済みのモデルを落とす例
.venv/bin/python fetch_model.py --help
```

`models.json` には作者が使っているモデルが登録済みなので、そこから好きなものを選べます。
初めてなら、甘めで濃いめの塗りの **FeMix HassakuXL** あたりが扱いやすいです。

モデルの実体は `~/AI-Models/` に置かれます。

### 4. 起動する

```bash
.venv/bin/python dashboard.py
```

ブラウザで **http://localhost:3942** を開けば、それがダッシュボードです。

> `Address already in use` と出たら、そのポートを他のアプリが使っています。別のポートで起動してください。
> ```bash
> IMG_FORGE_PORT=4000 .venv/bin/python dashboard.py
> ```

コマンドラインだけで焼きたいときはこちら。

```bash
.venv/bin/python generate.py -m femix-hassaku -p "1girl, solo, gentle smile, cafe" -c 4
```

> プロンプトは**本文タグだけ**渡してください。品質タグとネガティブは `models.json` から自動で足されます。

## このアプリがネットに繋ぐ場面（透明性のために）

生成そのものは完全にオフラインで動きます。通信するのは以下の3つの場面だけです。

1. **モデルのダウンロード時** — Hugging Face / Civitai から、あなたが指定したモデルを取得します
2. **モデルカタログの検索時** — ダッシュボードのモデルタブでCivitaiのAPIを叩きます
3. **モデルの作例サムネイル表示** — Civitaiの公式ギャラリー画像を直接読み込んで表示します

**生成したプロンプトや画像が、どこかに送信されることはありません。** 作者にも送られません（作者はあなたが何を焼いたか知る手段を持っていません）。

`CIVITAI_TOKEN` を設定した場合、そのキーはCivitaiへのダウンロード要求にのみ使われます。

## 注意・制約

- **モデルのライセンスは各自で確認してください。** Civitaiのモデルはそれぞれ利用条件が違い、商用利用可のものも、非商用限定のものもあります。生成した画像を仕事や販売に使う予定があるなら、必ずモデルの配布ページを読んでください。**このアプリのライセンスは、モデルの利用条件には一切影響しません。**
