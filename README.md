# img-forge — Macの中に置く、画像の鍛冶場

Apple Silicon（M1以降）のMacで、Stable Diffusion系の画像生成を**自分のパソコンの中だけ**で動かすWebアプリです。
ブラウザからプロンプトを入れて焼く、寝ている間に100枚バッチで焼く、焼けた絵を高速で仕分ける——このあたりを一式でまかないます。

**何枚焼いても料金はかかりません。**かかるのは電気代だけです。

> 作者（Kino）が自分用に作って、自分で毎日使っている道具です。完璧な製品ではなく、**改造してもらう前提の叩き台**として配っています。

---

## 動く環境（ここは正直に）

| 項目 | 条件 |
|---|---|
| マシン | **Apple Silicon Mac**（M1以降。作者はM4で開発・確認） |
| メモリ | 16GB以上を推奨（8GBは厳しい） |
| ディスク | モデル1本あたり6〜7GB。最低でも30GBは空けておく |
| Python | **3.10〜3.13**（作者は3.12）。3.14では顔補正が動きません |

**Intel Macでは動きません。Windows / Linuxも対象外です**（GPUの呼び出し方がApple製チップ専用のため）。

生成速度の目安は、1024px級で**1枚あたり2分前後**。速さで殴るタイプではないので、「寝る前に仕込んで朝見る」使い方が向いています。

---

## できること

- **単発生成** — プロンプトを入れて、モデルを選んで、枚数を決めて焼く
- **夜間バッチ** — プロンプトを並べたテキストファイルを渡すと、順番に全部焼く
- **レビュー** — 焼けた画像を一覧して、キーボードで採用／ボツを高速に仕分ける
- **スタイル（当たり設定の保存）** — モデル・絵柄タグ・ネガティブをまとめて名前で保存。絵柄だけ固定して、中身は毎回自由に
- **XYZスイープ** — 設定を総当たりで焼いて比較表にする。新しいモデルの「当たり値探し」用
- **兄弟を8枚焼く** — 惜しい絵を出発点に、構図と色を保ったまま細部違いを量産
- **自動採点** — 8枚以上焼くとアニメ美的スコアを付けて、点数順に並べられる
- **モデル管理** — Civitaiのカタログを検索して、その場でダウンロード・登録

### いちばんおすすめの使い方

このアプリは**コマンドラインからも全部叩けます**。なので、Claude CodeのようなターミナルのAIエージェントに、

> 「こういうイメージで100枚焼いといて」

と日本語で頼むと、プロンプトを100本考えるところからバッチ投入まで全部やってくれます（そのためのスキルを同梱しています → [AIエージェントに操作させる](#aiエージェントに操作させるおすすめ)）。

**焼くのが無料だから、数打てば当たるを正面からやれる**——これがこの道具の一番おいしいところです。

## セットアップ（約15分＋モデルのダウンロード時間）

> **いちばん早い道**: このフォルダごとClaude CodeなどのAIエージェントに読ませて、
> **「READMEの通りにセットアップして」** と頼んでください。以下の手順をだいたい全部やってくれます。
> 自分の手で進めたい方は、そのまま下へどうぞ。

### 1. 手元に持ってくる

```bash
git clone https://github.com/kino176222/img-forge.git
cd img-forge
```

gitが使えない場合は、GitHubページの緑の「Code」ボタン →「Download ZIP」で落として展開してください。

置き場所はどこでも構いません（パスの決め打ちはしていません）。

```
img-forge/
├── generate.py       … 生成本体（コマンドライン）
├── dashboard.py      … Webダッシュボード
├── fetch_model.py    … モデル追加ツール
├── models.json       … モデル台帳（当たり設定はここに入っています）
├── styles.json       … スタイル（絵柄プリセット）
├── requirements.txt  … 依存パッケージ
└── skills/
    └── local-image-gen/  … AIエージェント用スキル（後述・任意）
```

### 2. Pythonの環境を作る

まず `python3 --version` を実行してください。`Python 3.10` 以上が表示されればOKです。
「コマンドラインデベロッパツールをインストール」というダイアログが出たら、案内どおりに入れてから戻ってきてください。

確認できたら、`img-forge` フォルダの中で以下を順に実行します。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
```

PyTorchなど大きいものが入るので、回線によっては10分ほどかかります。

### 3. 1枚焼いてみる（モデルの準備は要りません）

**モデルのダウンロード作業は不要です。** 初回の生成時に自動で取得されます。

```bash
.venv/bin/python generate.py -m femix-hassaku -p "1girl, solo, gentle smile, cafe" -c 1
```

**初回だけ、モデルのダウンロードで5〜15分ほど止まります**（6〜7GB）。これは正常です。2回目以降はキャッシュから読むので、待ち時間は数十秒になります。

成功すると、こう表示されます。

```
[img-forge] model=femix-hassaku sampler=euler_a steps=28 cfg=5.5 ... total=1枚 out=.../output/20260807_0936_gen
[img-forge] モデル読み込み 51s
[img-forge] 1/1 femix-hassaku_p00_s1999503178.png 顔補正1箇所 (101s)
[img-forge] 生成完走 1枚 / 152s → .../output/20260807_0936_gen
```

`output/` の中に画像ができていれば成功です。

> プロンプトは**本文タグだけ**渡してください。「masterpiece, best quality」のような品質タグと、ネガティブプロンプトは `models.json` から自動で足されます。二重に書く必要はありません。

**プロンプトの書き方に3つだけコツがあります。**

- **文章ではなく、カンマ区切りの短い英単語で書きます**（`1girl, solo, gentle smile, cafe`）。アニメ系モデル共通のタグ記法で、英作文は効きません
- **長く書きすぎると後半が黙って切り捨てられます**（77トークン制限）。大事なタグほど前に置いてください
- **画像サイズはSDXLの得意な範囲（約100万画素）に収めます**。既定の832×1216のままが安全です。`-W 2048 -H 2048` のような大判はメモリ逼迫と破綻の原因になるので、大きくしたいときは生成後に `--hires` で拡大してください

**最初から入っているモデル**（すべて自動ダウンロード対応）

- `femix-hassaku` — 甘め・濃いめの塗り。**迷ったらこれ**（生成画像の商用利用: 可）
- `animagine` — 濃いめの塗り。キャラ立ち絵向き（生成画像の商用利用: 可）
- `nova-anime` — Illustrious系の定番。画面の情報量が多い（⚠ **未加工の生成画像は商用利用不可**。大きく加筆修正すれば可）

各モデルのライセンスは `models.json` の `license` 欄にも書いてあります（2026-08-07時点で配布ページを確認した内容）。**最終判断は必ず配布元のページを見てください。**

### 仕事に使う絵を焼くときは `--commercial` を付ける

生成した絵を仕事（記事・教材・アプリ・販売物）に使う予定があるなら、このオプションを付けてください。

```bash
.venv/bin/python generate.py -m femix-hassaku -p "..." --commercial
```

`models.json` の `license` 欄が**商用可と読めないモデルを、生成前に弾きます**。

```
[img-forge] --commercial なので中止します。
  モデル 'noobai' のライセンス: ⚠ 生成画像を含む商用利用は不可（…）
  商用可と読めるモデル: femix-hassaku, animagine
```

判定は**曖昧なら通さない**方に倒しています（「要確認」も弾く）。迷ったときに止まるほうが、後から作り直すより安いからです。

**なぜこれが要るか**：モデルによって「生成した絵を仕事に使えるか」が違い、**間違えると後戻りできません**（公開済みの記事や商品の差し替えになる）。人間の注意力に頼らず、機械で止める作りにしています。

> ⚠️ **Civitaiの「商用利用」表示は当てになりません。** モデルページには可否のトグル（構造化データ）とは別に、作者が本文へ書いたルールがあり、**両者が食い違うことがあります**。実例として `nova-anime` はトグル上「生成画像OK」ですが、本文には「未加工の生成画像は商用利用不可」と書かれています。
> 本アプリのモデルタブでは、**本文に商用制限の記述を見つけた場合、トグルの表示より安全側に倒して「本文に制限あり（要確認）」と出します**。それでも最終判断は本文を読んでください。

### 4. ダッシュボードを開く

```bash
.venv/bin/python dashboard.py
```

ブラウザで **http://localhost:3942** を開けば、それがダッシュボードです。生成・レビュー・モデル管理が全部ここでできます。

> **起動するとターミナルは入力を受け付けなくなります。それが正常です。**
> 止めるときは、そのターミナルで `Control + C`。
> 動かしたままコマンドも打ちたいときは、ターミナルの新しいタブ（⌘T）を開いて `cd img-forge` してください。

> `Address already in use` と出たら、そのポートを他のアプリが使っています。別のポートで起動してください。
> ```bash
> IMG_FORGE_PORT=4000 .venv/bin/python dashboard.py
> ```

## モデルを増やす

好みの絵柄を足したくなったときの話です。**セットアップの段階では読まなくて大丈夫です。**

### いちばんラクな方法: ダッシュボードから探す

ダッシュボードの**モデルタブ**にCivitaiのカタログ検索が付いています。気になるモデルを見つけて「追加」を押すだけで、ダウンロードと台帳への登録が終わります。

### コマンドで追加する

Hugging Faceにあるモデルなら、こう追加します。

```bash
.venv/bin/python fetch_model.py \
  --name mymodel \
  --hf-repo <ユーザー名>/<リポジトリ名> \
  --hf-file <ファイル名.safetensors> \
  --label "表示名（お好みで）"
```

`--hf-file` は省略できません（リポジトリ内のどのファイルを落とすかの指定です）。

すでに手元に `.safetensors` ファイルがある場合は、登録だけできます。

```bash
.venv/bin/python fetch_model.py --name mymodel --local ~/AI-Models/mymodel.safetensors
```

モデルの実体の置き場は2種類あります。

- **最初から入っている3モデル**（自動ダウンロード型）… `~/.cache/huggingface/hub/` に入ります
- **`fetch_model.py` で追加したもの** … `~/AI-Models/` に入ります

容量を確認したいときは両方を見てください。

### 追加するとき、配布ページで必ず見るもの

1. **ライセンス** — 商用利用の可否。生成画像を仕事に使うなら必須の確認です
2. **推奨の品質タグ** — あれば `--quality "..."` に渡します
3. **V-prediction かどうか** — v-pred版なら `--vpred` を付けます。**これを間違えると灰色の壊れた絵しか出ません**

### Civitaiから直接落とす場合（ログインが必要なモデルのみ）

Civitaiからの直接ダウンロードは、モデルによって認証を求められます。その場合は、ご自身のAPIキーを環境変数に入れてください。

```bash
export CIVITAI_TOKEN="あなたのキー"   # civitai.com/user/account で発行
```

> `export` は**そのターミナルを閉じると消えます**。
> ダッシュボードのモデルタブから追加する場合は、**ダッシュボードを起動するのと同じタブで、起動前に** `export` してください（起動後では効きません）。
> 毎回やるのが面倒なら、`~/.zshrc` に同じ行を書き足しておきます。

> **先にHugging Faceのミラーを探すほうが早いです。** 人気モデルは有志がミラーしていることが多く、その場合は認証が要りません。
> `https://huggingface.co/api/models?search=<モデル名>` で検索できます。
>
> ⚠️ **ただし、ライセンスの判断は必ずCivitaiの本家ページで行ってください。**
> 有志のミラーはダウンロードが楽ですが、**ライセンス表示が本家と食い違っている実例があります**（本家で作者が追記した制限が、ミラー側に転記されていない）。ミラーは取得の利便のためだけに使ってください。

## AIエージェントに操作させる（おすすめ）

`skills/local-image-gen/` に、**Claude Code などのAIエージェント用のスキル**を同梱しています。

これを自分のスキル置き場（Claude Codeなら `~/.claude/skills/`）に**フォルダごとコピー**すると、

> 「和風で涼しげなイメージで50枚焼いといて」

のように日本語で頼めるようになります。プロンプトを50本考えるところから、バッチ実行、完了報告までをAIがやってくれます。

```bash
mkdir -p ~/.claude/skills
cp -R skills/local-image-gen ~/.claude/skills/
```

（`mkdir` は置き場がまだ無い場合のためのものです。すでにあれば何も起きません）

フォルダ名は `local-image-gen` のまま変えないでください（中の設定と一致している必要があります）。
img-forgeを `~/Developer/img-forge` 以外に置いた場合は、AIに「img-forgeは〇〇に置いたのでスキルのパスを直して」と頼めば済みます。

**プロンプトを自分で書かなくてよくなる**、というのがこの道具の一番おいしい使い方です。

## このアプリがネットに繋ぐ場面（透明性のために）

生成そのものは完全にオフラインで動きます。通信するのは以下の3つの場面だけです。

1. **モデルのダウンロード時** — Hugging Face / Civitai から、あなたが指定したモデルを取得します
2. **モデルカタログの検索時** — ダッシュボードのモデルタブでCivitaiのAPIを叩きます
3. **初回生成時の補助ファイル取得** — 黒画像を防ぐ修正版VAE（約300MB・Hugging Face）、顔検出モデル、拡大用モデル（約18MB・`--hires`使用時のみ）、8枚以上焼いたときの採点モデルを自動で取得します

モデルの作例サムネイルは、以前はCivitaiの画像を直接読み込んでいましたが、**他所の帯域を使うことと、閲覧のたびにあなたのIPアドレスがCivitaiに渡ることを避けるため、表示をやめました**（モデルタブのカタログ検索で、Civitaiのページを開けば作例は見られます）。

**生成したプロンプトや画像が、どこかに送信されることはありません。** 作者にも送られません（作者はあなたが何を焼いたか知る手段を持っていません）。

`CIVITAI_TOKEN` を設定した場合、そのキーはCivitaiへのダウンロード要求にのみ使われます。
