# local-image-gen — 「100枚焼いといて」が通じるようになるスキル

img-forge を **AIエージェントに操作させるための手順書**です。

これを入れておくと、Claude Code などのターミナル型AIに

> 「和風で涼しげなイメージで50枚焼いといて」

と日本語で頼むだけで、プロンプトを50本考えるところからバッチ実行、完了報告までをやってくれます。
**プロンプトを自分で書かなくてよくなる**、というのが一番の効果です。

## 入れ方（1分）

img-forge のセットアップが済んでいることが前提です（本体のREADMEを先にどうぞ）。

このフォルダを、お使いのAIエージェントのスキル置き場に**フォルダごと**コピーします。

```bash
cp -R skills/local-image-gen ~/.claude/skills/
```

`~/.claude/skills/` は Claude Code の既定の置き場です。他のツールを使っている場合は、そのツールのスキル置き場に読み替えてください。

> **フォルダ名は `local-image-gen` のまま変えないでください。** SKILL.md 内の名前と一致している必要があり、ずれると認識されません。

img-forge を `~/Developer/img-forge` 以外に置いた場合は、`SKILL.md` の「依存」の項にあるパスを書き換えます。
**最短ルート**: AIに「img-forgeは〇〇に置いたので、このスキルのパスを直して」と頼めば済みます。

## 依頼の例

- 「和風で涼しげなイメージで50枚焼いといて」
- 「このキャラで表情差分を20枚作って」
- 「新しく入れたモデルの品定めして」（XYZスイープが走ります）
- 「img-forgeのダッシュボード開いて」

夜に頼んで、朝に仕分ける——という使い方が一番おいしいです。
走らせる前に所要時間の見積もりが出ます（100枚で約3.5時間が目安）。長時間になる場合はバックグラウンドで実行され、終わったら報告が返ります。

## 注意

- 破綻した画像が混ざるのは正常です。多めに焼いて人間の目で選ぶ前提の設計になっています
- モデルのライセンス確認は代行しません。商用利用の可否はご自身で確認してください
- 動作環境は img-forge に準じます（Apple Silicon Mac のみ）
